About

Roman Shipovalov

I love it when routine work disappears: yesterday it was done by hand, today a program does it.

I build digital tools for businesses: websites, Telegram bots and mini apps, data collection and processing, and automation of repetitive work.

How I work

  • I start with the problem

    What the result should be, who will use it and how it’s done by hand today.

  • I build with AI

    I write code together with AI tools — Claude Code, Codex, Cursor. It’s faster, and I’m open about it.

  • I test in real conditions

    I walk through real scenarios on desktop and mobile and catch bugs before users do.

  • I see it through

    The result is something that works and gets used, not a slide deck.

I’m not a traditional programmer: I write code together with AI. My part is to understand the problem, frame the task, check the result and see it through.
